## Getting started

#### Open and run `mhw_detecion_demo.ipynb`
It should run out of the box, and will demonstrate the functionality of my detection algorithm. That's pretty much it!

## What's in this repo?

- The core functions used to implement a Hobday-style marine heatwave (MHW) detection algorithm are stored in `mhw_detection_functions.py`
- The demo notebook `mhw_detecion_demo.ipynb` contains a full tutorial in the usage of the functions
- `mhw_EDA.ipynb` contains some visualisations and working out for my first project: modelling MHWs as intensity-duration bivariate events
- `data/` contains the dataset required to run the demo notebook
- `images/` contains the pictures I use in my markdown docs and notebooks
